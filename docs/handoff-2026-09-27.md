     avoid — a smaller, free-tier one, but real. Worth a plain "yes, do this
     anyway" before it happens, since it's the opposite of an earlier decision
     in this project.

     to set whenever, but pointless before the above.
   - **Disable Web Analytics, Browser Insights, Zaraz, Rocket Loader, Email
     Obfuscation.** Dashboard-only, no API reached from this session. Rocket
     Loader and Email Obfuscation in particular inject their own JavaScript
     into responses if left on — worth confirming off precisely because this
     site's whole design is zero JavaScript.
